# 关于书境 FolioAtlas

书境把一本书中的人物、概念、地点与事件连接成可探索的阅读地图。本次展品以米兰·昆德拉《不能承受的生命之轻》为例，保留已有 Wiki 的信息架构、关系导航与交织时间线，提供精编概要。

## 从这里开始

- [[交织时间线]]：先看四幕十二个切片，再进入人物线。
- [[托马斯]]、[[特蕾莎]]、[[萨比娜]]、[[弗兰茨]]：并读四个人的关系与选择。
- [[轻与重]]、[[媚俗]]、[[永恒轮回]]：从概念返回具体处境。

## 项目与贡献

知识结构设计、人物与叙事组织、视觉一致性设计、内容校核与交付：蔡睿麟（Ruilin-mmwa）。使用 Claude Code / Codex 等工具协作实现。

底层 Wiki 路由、Markdown 渲染、检索与插件机制来自 Memex。书境沿用其现有界面和扩展方式，聚焦内容产品设计与本地定制。

## 本演示的范围

公开演示包含精编概要、自有生成视觉与关系导航。小说译本、章节全文和原句索引保留于个人本地阅读环境，不在本仓库中分发。本地完整版曾整理77个页面；本演示不将完整原文作为体验前提。

原作品著作权属于其权利人。画面为本项目 AI 辅助生成的叙事重建；发色、脸型等视觉设定不等同于原著事实。
